# Changelog

All notable changes to SVG Studio will be documented in this file.

## [2.2.0] — 2025-01-XX

### Added
- Context menu on right-click with 14 actions
- Group / ungroup functionality with `Ctrl+G` / `Ctrl+Shift+G`
- Clipboard: copy, cut, paste with auto-offset
- Z-order controls: bring to front, send to back, forward, backward
- 8 new shapes: Triangle, Diamond, Hexagon, Octagon, Arrow, Heart, Cross, Speech Bubble
- Group serialization to SVG `<g>` on export
- Group parsing on SVG import

### Changed
- Rebranded UI to Linear/Raycast-inspired dark theme
- Toolbar now scrollable with grouped dividers
- Layers panel shows group badges

## [2.1.0] — 2025-01-XX

### Added
- Extended geometry library
- Digit shortcuts `1`–`8` for new shapes

## [2.0.0] — 2025-01-XX

### Added
- Full TypeScript migration
- Modular architecture (18 modules)
- Modern UI redesign
